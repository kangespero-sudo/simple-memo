# 간단 메모장

## 실행

[메모장 열기](https://kangespero-sudo.github.io/simple-memo/) → 이메일·비밀번호로 회원가입 또는 로그인 → 메모 저장·삭제. `index.html` 한 파일을 사용하며 이메일 확인 없이 가입 직후 로그인됩니다.

## 검증 결과 (2026-10-30)

- 실제 배포 사이트에서 첫 화면, 회원가입·자동 로그인, 메모 저장·목록, 새로고침 후 로그인·메모 유지, 삭제, 로그아웃·재로그인 모두 통과.
- 다른 사용자 권한의 메모 조회·대신 저장·삭제 차단을 DB에서 확인. 검증 트랜잭션은 롤백.
- 모바일 너비 390px에서 가로 스크롤 없음, 입력 글자 16px, HTML 태그를 일반 텍스트로 표시함을 확인.
- Supabase 보안 점검 지적 사항 없음. 프런트엔드에는 공개용 키만 사용.
- 검증용 메모 삭제 완료. 검증용 계정 1개 유지.
- 미해결 사항 없음.
